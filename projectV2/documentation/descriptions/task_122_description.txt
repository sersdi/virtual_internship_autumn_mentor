Перед тем как запустить приложение на прод среде бизнес
просит реализовать включалку/выключалку для AgeCoefficient
при расчёте медицинского риска. Обоснование - бизнес не уверен
в том, что этот коэффициент нужно использовать для расчёта премии
и хочет иметь возможность быстро отключить использование этого
коэффициента если возникнет такая необходимость.

Задача:

Реализовать включалку/выключалку для AgeCoefficient так же
как это было сделано для InsuranceLimitCoefficient из
предыдущего задания.

Решение:

Добавил в application.properties: medical.risk.age.coefficient.enabled=true.
В классе AgeCoefficientCalculator обновил логику:
    добавил переменную private final Boolean medicalRiskAgeCoefficientEnabled.
    добавил конструктор вместо аннотации.
    изменил логику методов.

В классах добавил функционал с medical.risk.limit.level.enabled:false
    обновил EmptyMedicalRiskLimitLevelValidation.
    обновил MedicalRiskLimitLevelValidation.
    Переписал тесты MedicalRiskLimitLevelValidationTest с новой логикой,
                    EmptyMedicalRiskLimitLevelValidationTest,
