Открыл Spring Boot приложение через класс InsuranceApplication.
Попробовал запустить его копию одновременно, но получил ошибку, что порт уже занят.
Это связано с тем, что Spring Boot по умолчанию использует один и тот же порт (обычно 8080) для запуска приложения.
Чтобы запустить две копии одновременно, необходимо изменить порт для одной из копий, например, через параметр командной строки или в файле application.properties.
