Узнал про stateless(объекты без состояния) и stateful(имеет состояние) объекты.
Stateless объекты считаются потоко-безопасными,
    так-как у них нет внутреннего изменяемого состояния,
        которое могло бы совместно использоваться несколькими потоками.
Stateful объект - экземпляр класса, чьи поля (переменные экземпляра) могут меняться со временем в результате выполнения методов.
Его поведение зависит от предыдущих операций над ним, то есть объект переходит из одного состояния в другое.
Поэтому stateful объекты не потоко-безопасные
