Core Concepts

discussed in the provided excerpts.

Lombok for Constructor Generation

Purpose of Lombok:
Automates the generation of boilerplate code in Java,
such as constructors, getters, and setters, reducing
verbosity and improving code readability.

@RequiredArgsConstructor Annotation:
Specifically used to generate a constructor with arguments
for all final fields that are not initialized.

AccessLevel.PACKAGE:
Specifies that the generated constructor will have
package-private access, meaning it can only be accessed
by classes within the same package.

final fields:
For @RequiredArgsConstructor to include a class property
as a constructor parameter, that property must be declared as final.

Field Injection (as per "Why Field Injection is Evil")

Definition:
A dependency injection technique where dependencies
are injected directly into a class's fields using
annotations (e.g., @Autowired in Spring).

Criticisms of Field Injection:
The "Why Field Injection is Evil" document likely details
the drawbacks of this approach. Common criticisms include:

Reduced Testability:
Difficult to instantiate objects in tests without a
dependency injection framework, leading to tightly coupled tests.

Hidden Dependencies:
Dependencies are not explicitly declared in the constructor,
making it harder to understand a class's requirements at a glance.

Lack of Immutability:
Often used with mutable fields, making it harder to reason
about object state.

Circular Dependencies:
Can lead to hard-to-debug circular dependency issues.

Reliance on Framework:
Classes become highly reliant on the dependency injection
framework, making them less portable.

Build Tools and Output Directories

IDEA:
When building a project with IntelliJ IDEA, generated
Lombok code (compiled .class files) can be found in
out/production/classes.

Gradle:
When building a project with Gradle, generated
Lombok code can be found in build/classes.

Importance of Inspection:
It's crucial to inspect these directories after compilation
to observe the actual code generated by Lombok.
