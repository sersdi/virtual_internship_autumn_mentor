Glossary of Key Terms

Artifacts (Артефакты):
Files or components produced during the software development
process, particularly during a build. These can include
compiled code, libraries, reports, and documentation.

Bytecode (Байт-код):
An intermediate form of code that a computer's processor
can execute after it has been translated from source code.
In Java, bytecode is typically stored in .class files.

Classes (Классы):
A fundamental building block in object-oriented programming,
defining the blueprint for creating objects. In the context
of the build, these refer to the compiled .class files.

Compilation (Компиляция):
The process of transforming source code written in a
high-level programming language into a lower-level language,
such as bytecode or machine code, that a computer can
understand and execute.

Gradle Build (Сборка Gradle):
The process of compiling, assembling, and often testing
a software project using the Gradle build automation tool.
It transforms source code into a deployable application.

JAR File (Java Archive File):
A package file format used to aggregate many Java class files,
associated metadata, and resources (text, images, etc.)
into one file for distribution.

Production Classes (Продакшн классы):
The core classes that constitute the actual functionality
of the application, intended for deployment and end-user use.

Reports (Отчеты):
Documents or files generated by the build process,
often summarizing the results of tests, code quality analysis,
or other build steps.

Resources (Ресурсы):
Non-code files that an application needs to run,
such as configuration files, images, sounds, or localization data.

Test Classes (Тестовые классы):
Classes specifically written to verify the correctness
and functionality of the production code. They are not
part of the deployed application itself but are crucial
for quality assurance.

Test Results (Результаты выполнения тестов):
Data or files containing the outcomes of executed tests,
indicating which tests passed or failed and providing
details about any failures.
