Glossary of Key Terms

Artifacts:
Files or outputs generated by Gradle during the application
build process, such as compiled code, resource files, or
packaged applications.

Build Folder (build):
A directory created by Gradle during the build process,
where all generated artifacts and intermediate files are stored.
It is typically highlighted in red in IDEA.

Clean Command (clean):
A Gradle command specifically designed to remove all artifacts
and the build folder generated during a project's build process,
ensuring a clean slate.

Build Command (build):
A Gradle command used to compile, package, and generate the
final application artifacts. Mentioned as analogous to clean.

Gradle:
An open-source build automation tool used for automating
the building, testing, publishing, and deployment of software.

Module:
A distinct, self-contained unit within a larger Gradle project,
often representing a specific component or library.

Terminal:
A text-based interface used to interact with the operating
system and execute commands, including Gradle commands.

IDEA (IntelliJ IDEA):
A popular integrated development environment (IDE) for Java
and other programming languages, which has integrated support
for Gradle.
