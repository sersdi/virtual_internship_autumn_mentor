Glossary of Key Terms

Logback:
A fast and reliable logging framework for Java applications.
It is the successor to Log4j and provides a robust logging solution.

Configuration:
The setup instructions that define how a software component
or system should operate. In Logback, this typically involves
specifying appenders, loggers, and logging levels.

Logging System:
A software framework or component designed to record events,
errors, and other diagnostic information generated by an
application during its execution.

Appender:
A Logback component responsible for writing log events to a
specific output destination. Examples include ConsoleAppender,
FileAppender, RollingFileAppender, etc.

Console Appender (ConsoleAppender):
A specific type of Logback appender that sends log messages to
the standard console output (typically System.out or System.err).

Java Application:
A software program written in the Java programming language.
