Quiz Answer Key

1. The primary issue identified is a significant amount
   of duplicated code within the tests.

2. Code duplication in tests is problematic because
   it makes the test suite much harder to maintain and
   can lead to the tests degrading into "junk."

3. The ultimate goal when refactoring duplicated test
   code is to achieve high-quality and maintainable test code.

4. Test data, specifically requests and responses, are
   currently intermingled with the test code itself, which
   leads to a large amount of repetition.

5. The ideal test structure involves taking a request as JSON,
   executing it to get a real response, taking an expected response,
   and then comparing the expected and real responses.

6. In the ideal scenario, what differentiates each test is only
   the specific request being sent and the expected response
   that is anticipated.

7. Separating test data from code addresses duplication by
   allowing the core test logic to remain identical across
   multiple tests, as only the data (requests and expected
   responses) will change.

8. The suggested new directory to store the separated
   test data is src/test/resources/rest.

9. The test data files should use the .json file extension.

10. Both requests and their corresponding expected responses
    should be stored as JSON files in the new directory.
