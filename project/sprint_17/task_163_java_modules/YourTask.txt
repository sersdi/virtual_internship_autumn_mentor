A Guide to Java Modularity

В Java 9 появились новые возможности для модульной организации кода.

Была представлена модульная система Java (Java Platform Module System, JPMS).

В этом опциональном задании предлагается
погрузиться в эту тему и изучить концепции
модульной организации кода в Java.

Для начала прочитайте несколько статей из списка ниже:

https://www.baeldung.com/java-modularity
https://habr.com/ru/articles/499872/
https://habr.com/ru/companies/otus/articles/798901/

Для более глубокого погружения в тему:
https://dev.java/learn/modules/

В коде проекта вы найдете пример использования модулей
на примере пакета core. Пакет core был разделен на отдельные модули.

В файлах объявлений модулей есть описание зависимостей
от других модулей. Теперь у нас есть четкое наглядное
представление того, какие модули зависят друг от друга.

Это задание опциональное и все оставшиеся задания проекта
не используют модульную организацию кода.

У вас есть несколько вариантов:
1. Внедрить модульную организацию кода
   в проекте и поддерживать ее самостоятельно.
2. Сделать отдельный бранч в репозитории и внедрить
   модульную организацию кода в проекте в отдельном бранче.
3. Ничего не делать с точки зрения практики внедрения модульной
   организации кода и просто перейти к следующим заданиям проекта.
