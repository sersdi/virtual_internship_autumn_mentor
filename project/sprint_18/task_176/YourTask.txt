Продолжаем работать над разработкой REST вызова для получения
полной информации по полису страхования используя уникальный
идентификатор полиса.

Ваша задача:
- разработать новый REST контроллер по получению полиса по "uuid";
- контроллер должен принимать GET запросы на url
  /insurance/travel/api/internal/agreement/{uuid};
- пока не реализована логика пусть контроллер всегда возвращает
  статически заданный результат;
- запустить приложение и убедиться, что новый REST контролёр работает.
