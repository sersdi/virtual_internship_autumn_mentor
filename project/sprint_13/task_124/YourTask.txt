Поздравляем! Клиент принял решение установить разработанное
нами приложение на своей тестовой среде. Клиент просит нас подготовить
Fat Jar файл для нашего приложения. Fat Jar должен иметь
название insurance-calculator-1.0.0.jar и запускаться
командой из консольной строки:
java -jar insurance-calculator-1.0.0.jar

Ваша задача:

1. Разобраться в разных деплоймент артефактах: Thin Jar, Fat Jar, Thin War, Fat War.

2. Разобраться в командах Gradle предназначенных для создания деплоймент артефактов.

3. Разобраться с конфигурацией добавленной ментором в build.gradle файл.

4. Сгенерировать требуемый деплоймент артефакт и протестировать его запуск.

5. Поэкспериментировать с созданием различных деплоймент артефактов:
Thin Jar, Fat Jar, Thin War, Fat War и изучить их внутреннюю структуру.
