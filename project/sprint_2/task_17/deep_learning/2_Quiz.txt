Quiz Answer Key

1. The primary objective is to calculate the agreementPrice
   by determining the number of days between agreementDateFrom
   and agreementDateTo. This calculation is a foundational step,
   even though the current value is a placeholder.

2. Developers are specifically instructed to research and apply
   a standard Java solution for calculating the number of days
   between two dates. This promotes the use of existing, proven
   library functions.

3. The agreementPrice is described as a "fake value" because
   its current calculation is a placeholder, and the true,
   complex business logic for it will be implemented later
   in the project. This allows for incremental development.

4. The guide emphasizes the principle that good programmers
   should discern when to write new code and when to utilize
   readily available, standard solutions found online.
   This promotes efficiency and reliability.

5. Developers are explicitly instructed to run all their
   tests before committing any changes to the repository.
   This ensures the stability and correctness of the codebase
   before integration.

6. If tests are broken or not passing (not "green") before
   committing, the developer must fix them first. Committing
   broken code is unacceptable, as it can introduce regressions
   into the main repository.

7. The purpose of starting with "very simple" tasks is to help
   new developers gradually ease into the project, become
   familiar with the development process, and build confidence.
   It's a gentle onboarding strategy.

8. Besides technical implementation, the guide aims to help
   developers get accustomed to the overall development process,
   establish communication with mentors, and collaborate
   effectively with colleagues. It focuses on team integration.

9. No, it is not acceptable to commit code if some tests
   are failing. The guide explicitly states that all tests must
   pass ("be green") before committing, and broken tests must
   be fixed prior to submission.

10. The implementation of the "real business requirements"
    for the agreementPrice calculation is stated to begin
    around "step 30" of the project. This indicates a phased
    approach to feature development.
