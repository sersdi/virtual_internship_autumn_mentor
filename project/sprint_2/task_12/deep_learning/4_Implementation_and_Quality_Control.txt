What is a crucial step to perform before committing
changes to the local repository?

Before committing any changes to the local repository,
it is essential to always run a build of your module.

Why is it important to run a module build before committing?

Running a module build before committing allows developers
to catch and fix errors during the development phase itself.
This prevents errors from propagating to the global repository
and causing a project build failure on GitHub.

What are the consequences of failing a project build on GitHub?

If a developer fails a project build on GitHub, there will
be accountability for that failure ("за вами все равно придут!").
This emphasizes the importance of preventing such incidents.

How are commits in the global repository tracked?

Any commits made to the global repository are added under
the individual user's account, and the entire history of
these commits is accessible on GitHub. This highlights the
traceability and transparency of contributions.
